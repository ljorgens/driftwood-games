Driftwood Games

Every Driftwood game is open source, so you can change the map, the rules or the AI and share your own version. Send it in, and I’ll feature the best ones here.

You don’t need to ask

The code is on GitHub under the MIT License, so it’s yours to use. You can copy it, change anything, and publish your version wherever you like, with no permission needed. The license asks only that you keep its file and copyright line. And because Tempest Isles is itself a tribute, please don’t use the original Isle Wars Pro name, art or text. On GitHub you can also:

  • Fork the repo to start your own version: fork Tempest Isles (opens in a new tab).
  • Improve the original by opening a pull request (opens in a new tab). Good fixes and features can be merged into the game everyone plays.
  • Report a bug or suggest a change in the issues (opens in a new tab).

Getting a mod listed on this page is optional. It’s just a way to help players find it.

    Make your own version

    1. Fork or download the game’s code from GitHub (opens in a new tab).
    2. Follow the modding guide (opens in a new tab). It shows where the map, rules, cards, disasters and AI live. The map is plain text, so you can redraw the islands without any art tools.
    3. Put it online for free, for example on GitHub Pages or itch.io. The guide explains how.
    4. To get it listed here, email the link to driftwoodgames@proton.me, with a line about what you changed and the name you’d like to be credited by.

    What gets featured

    I try every mod that comes in. To be featured, a mod needs to:

    • be free to play, with no ads, trackers, sign-ups or downloads;
    • have its own name (a subtitle like “Tempest Isles: Archipelago” is fine if it says it’s based on our game), and keep the original license and credits;
    • use only material you have the right to use: nothing from the original commercial games, including their names;
    • be suitable for all ages, and work well on a computer (phones are a bonus).

    Featured mods are made and hosted by their creators, not by me. I check each one when I feature it, but it may change after that, and I may remove a link at any time. See the terms.
